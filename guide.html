찜콩 사용법

찜콩은 전도집회에 초청한 분이 앉을 강의실 자리를 미리 찜해 두는 웹페이지예요. 앱을 깔 필요 없이 휴대폰 · PC 브라우저에서 바로 돼요.

성도용 — 자리 찜하기

한눈에 보기

  • 관리자가 단체방에 올린 찜콩 초대 링크를 누르면 시작돼요.
  • 빈자리를 누르면 내 자리가 돼요.
  • 내 자리를 다시 누르면 취소돼요.
  • 좌석표는 20초마다 저절로 새로 고쳐져요.

처음 연결하기

  1. 단체방에 올라온 찜콩 초대 링크를 누르세요. 초대 QR 이면 휴대폰 카메라로 찍으세요.
  2. 찜콩이 열리고 연결 코드가 저절로 들어가 있어요.
  3. 내 이름 칸에 이름을 적으세요. 좌석표에 이 이름이 보여요.
  4. 연결 코드 아래 확인 번호(8자리)가 관리자 공지의 번호와 같은지 보세요.
  5. 같으면 [연결]을 누르세요.
확인 번호가 다르면 연결하지 마세요 가짜 링크일 수 있어요. 관리자에게 먼저 물어보세요.

연결은 한 번이면 돼요. 같은 기기 · 같은 브라우저로 다시 오면 바로 좌석표가 보여요.

자리 찜하기 · 옮기기 · 취소

  1. 빈자리를 누르면 바로 찜돼요. 내 자리는 금색으로 바뀌고, 위에 내 자리: A5 처럼 보여요.
  2. 다른 빈자리를 누르면 그리로 옮겨져요(한 사람 한 자리일 때).
  3. 내 자리(금색)를 다시 누르면 취소할지 물어요. 예를 누르면 취소돼요.
  • 이름 칸이 비어 있으면 찜이 안 돼요. 이름부터 적어 주세요.
  • 관리자가 한 사람이 여러 자리(가족 몫)를 잡게 해 두었으면, 옮기지 않고 한 자리 더 잡혀요. 몇 자리까지인지는 좌석표 위 안내 글에 나와요.
  • 강의실이 2층 이상이면 위쪽 1층 · 2층 단추로 층을 바꿔 보세요.

좌석표 읽기

  • 빈자리: 눌러서 찜할 수 있어요.
  • 내 자리: 금색이에요.
  • 예약됨: 다른 분 자리예요. 관리자가 켜 두면 이름도 보여요.
  • 앉을 수 없음(×): 관리자가 막아 둔 자리예요.
  • 책상 의자는 위쪽 변이 굵고, 보조 의자는 주황 테두리예요. 장의자는 붙은 긴 의자로, 한 칸이 한 사람 자리예요.
  • 부채꼴 · 원형 강의실은 무대에 가까운 줄부터 A, B, … 예요.

이렇게 보이면

  • "그 사이 다른 분이 먼저 잡았어요": 다른 자리를 골라 주세요.
  • "아직 예약을 받지 않아요": 관리자가 아직 열지 않았어요. 열리면 저절로 보여요.
  • "○○부터 예약할 수 있어요" · "예약이 마감됐어요": 정해진 예약 시간이 아니에요.
  • "인터넷에 연결되어 있는지 확인해 주세요": 와이파이나 데이터를 켜 주세요.
브라우저 기록을 지우거나 기기를 바꾸면 "나"는 그 브라우저에만 기억돼요. 찜한 뒤 오른쪽 [내 자리 지키기] 에서 둘 중 하나를 해 두세요.
  • 내 자리 링크 복사: 카톡 '나와의 채팅'이나 메모에 붙여 두세요. 어느 기기에서든 그 링크를 누르면 내 자리로 들어가요. 남에게 보내지 마세요.
  • 비밀번호 정하기: 이름과 숫자 4자리를 정해 두면, 새 기기에서 초대 링크로 연결한 뒤 [내 자리 되찾기] 로 돌아올 수 있어요.
둘 다 안 해 뒀다면 관리자에게 그 자리를 취소해 달라고 한 뒤 다시 찜해 주세요.
개인정보 예약 기록과 이름은 관리자(교회)의 구글 시트에만 저장돼요. 찜콩은 따로 모으지 않아요.

관리자용 — 좌석 예약 열기

구글 시트 하나로 좌석 예약을 받아요. 시트 · 예약 기록 · 이름은 모두 관리자의 구글 드라이브에만 있어요. 처음 준비는 PC 에서 한 번, 10분쯤 걸려요.

Hagah 앱의 좌석 예약과 같은 시트를 써요. Hagah 로 만든 시트도 찜콩에서 그대로 돼요.

① 시트 복사하고 처음 설정

  1. 구글 계정으로 로그인한 PC 브라우저에서 템플릿 시트 사본 만들기를 여세요.
  2. [사본 만들기]를 누르세요. 내 드라이브에 시트가 생겨요.
  3. 사본 시트가 열리면 잠시 기다리거나 새로 고치세요. 위 메뉴 끝에 [좌석 예약]이 생겨요.
  4. [좌석 예약] → [1. 처음 설정 시작]을 누르세요.
  5. "승인 필요" 창에서 [확인] → 계정 고르기. 팝업이 막히면 주소창 오른쪽에서 허용해 주세요.
  6. "Google에서 확인하지 않은 앱" 경고가 나오면 [고급] → 맨 아래 "…(으)로 이동(안전하지 않음)"을 누르세요. 개발자는 관리자 자신이에요. 내 시트를 내 스크립트가 고치는 거라 안전해요.
  7. 권한 화면에서 "모두 선택"에 체크하고 [계속]을 누르세요.
  8. "좌석 예약 처음 설정" 창에 강의실 이름을 넣고 [확인]. 탭 5개(설정 · 좌석 · 예약 · 지난 예약 · 기록)가 생겨요.
가장 막히기 쉬운 곳 — "모두 선택" 권한 화면의 체크 상자는 처음엔 비어 있어요. 체크하지 않고 계속을 누르면 나중에 찜콩 연결이 안 돼요. 꼭 "모두 선택"(Select all)을 누르세요. 단추가 아래에 있어 화면을 내려야 보일 수 있어요.

② 웹 앱 만들기(배포)

  1. 시트 위 메뉴 [확장 프로그램] → [Apps Script]. 코드는 건드리지 않아요.
  2. 오른쪽 위 [배포] → [새 배포].
  3. "유형 선택" 옆 톱니바퀴 → [웹 앱].
  4. 실행: 나 · 액세스 권한: 모든 사용자 → [배포].
  5. "액세스 승인"이 나오면 ①과 같은 순서로 한 번 더 허락하세요(모두 선택 잊지 마세요).
  6. 웹 앱 URL 아래 [복사] → [완료].
액세스는 그냥 "모든 사용자" "Google 계정이 있는 모든 사용자"를 고르면 성도가 연결되지 않아요.

③ 찜콩에 관리자로 연결

  1. 시트로 돌아와 [좌석 예약] → [2. 연결 QR 보기].
  2. 처음 한 번 웹 앱 주소를 물어요. 복사한 주소(https://script.google.com/macros/s/…/exec)를 붙여 넣으세요.
  3. 오른쪽 관리자용 QR 아래 글(주소#admin=키)을 복사하세요.
  4. 찜콩 첫 화면에서 이름을 적고, 연결 코드 칸에 붙여 넣은 뒤 [연결].
  5. 강의실 이름 옆에 관리자 표시가 보이면 돼요.
시트에 'Hagah' 라고 적혀 있어도 괜찮아요 시트 대화상자 문구는 Hagah 앱 기준이에요. 같은 글을 찜콩에 붙여 넣으면 그대로 돼요. 주소를 잘못 넣었으면 [좌석 예약] → [웹 앱 주소 다시 넣기].
관리자 글은 남에게 보여 주지 마세요 받은 사람은 배치도를 고치고 예약을 지울 수 있어요. 새어 나갔으면 시트 메뉴 [좌석 예약] → [관리자 키 새로 만들기]를 누르고, 새 관리자 글로 다시 연결하세요. 성도 초대 링크는 그대로 써도 돼요.

④ 배치도 그리기

  1. [배치도 고치기]를 누르세요.
  2. 도구를 고르고 칸을 누르거나 끌어 칠하세요.
    • 1인 의자 · 책상 의자 · 장의자 · 보조 의자: 그 의자를 놓아요. 장의자는 한 줄로 끌면 긴 의자 하나가 돼요.
    • 앉을 수 없음: 자리는 두되 찜은 못 하게 막아요(×). 다시 칠하면 풀려요.
    • 통로(지우기): 의자를 없애요.
  3. 모양을 고르세요. 네모 · 부채꼴 · 원형. 부채꼴 · 원형은 각도를 15°씩 늘리고 줄여요.
  4. 줄 · 칸 단추로 판을 늘리고 줄이세요.
  5. 2층 이상이면 + 층으로 층을 더하세요(최대 9층). 층마다 모양을 따로 고를 수 있어요.
  6. 다 그렸으면 [저장]. 그만두려면 [그만].
  • 의자는 모든 층을 합해 2000석까지예요.
  • 이름표(A1, A2, …)는 저장할 때 저절로 붙어요.
  • 예약이 있는 자리를 지우면 저장 전에 알려 줘요. 남은 자리의 예약은 그대로예요.

⑤ 예약 받기

  1. [공개]를 켜세요. 그래야 성도에게 좌석표가 보여요.
  2. [초대 링크 복사] 또는 [초대 QR]로 단체방에 나눠 주세요.
  3. 이름 옆 확인 번호(8자리)도 단체방 공지에 적어 두세요. 가짜 링크를 가려내는 데 써요.
성도에게는 찜콩 초대 링크 · QR 을 주세요 시트의 성도용 QR(웹 앱 주소)을 휴대폰 카메라로 바로 찍으면 Apps Script 안내 페이지만 떠요. 꼭 찜콩의 [초대 링크 복사] · [초대 QR]을 쓰세요.

필요할 때 쓰는 것

  • 이름 보이기: 끄면 성도에게는 남의 자리가 "예약됨"으로만 보여요. 관리자에게는 늘 보여요.
  • 1인 최대: 가족 몫까지 잡게 하려면 늘리세요. 1이면 다른 자리를 누를 때 옮기기가 돼요.
  • 관리자 취소: 남의 예약 자리를 누르면 취소할지 물어요. 기기를 바꿔 자기 자리를 못 지우는 분께 써 주세요.
  • [다음 회차로]: 예약을 모두 시트의 '지난 예약' 탭으로 옮기고 좌석표를 비워요. 배치도와 공개는 그대로예요.
  • 여는 · 닫는 시각: 시트 [설정] 탭에 손으로 넣어요. 예: 2026-12-01 21:00. 비워 두면 공개하자마자 받고 닫지 않아요.

이럴 땐

  • [좌석 예약] 메뉴가 안 보여요: 시트를 새로 고치고 10초쯤 기다리세요.
  • 찜콩 연결이 안 돼요: 대개 "모두 선택"을 안 했거나 액세스가 "모든 사용자"가 아니에요. Apps Script [배포] → [배포 관리] → 연필에서 고치고 버전 [새 버전] → [배포] 하세요. 주소는 그대로예요.
  • 스크립트를 고쳤어요: 위와 같이 [배포 관리] → 연필 → 새 버전으로 다시 배포하세요.
  • 같은 자리를 동시에 누르면 먼저 온 한 사람만 잡혀요. 수십 명이 한 시각에 몰리는 "선착순 오픈"에는 맞지 않아요.
개인정보 예약 기록과 이름은 관리자의 구글 시트에만 저장돼요. 찜콩은 따로 모으지 않아요.
