# 찜콩 번역 지침

## 찜콩이 무엇인가
교회가 전도집회 같은 모임을 열 때, 초대받은 손님(아직 교회에 다니지 않는 분이 많음)이 앉을 강의실 자리를
웹에서 **미리 맡아 두는(찜하는)** 무료 웹페이지다. 사용자는 두 부류다.
- **성도 · 손님**: 초대 링크를 받아 이름을 적고 빈자리를 눌러 맡는다. 기술에 익숙하지 않은 분이 많다.
- **관리자(교회 담당자)**: 구글 시트를 복사해 웹 앱으로 배포하고, 배치도를 그리고, 예약을 연다.

## 말투
- 따뜻하고 공손하며 쉬운 말. 짧은 문장. 그 언어의 일반적인 앱 · 웹사이트 문구처럼 자연스럽게.
- 존댓말이 있는 언어(일본어 · 태국어 등)는 정중체, 독일어 · 프랑스어 등은 존칭(Sie / vous) 대신
  그 언어 앱에서 흔한 쪽을 쓰되 한 파일 안에서는 하나로 통일.
- 단추 · 제목 · 칩처럼 짧은 글은 짧게(가능하면 원문 길이의 1.5배 이내).

## 꼭 지킬 것
1. **자리표시 `{n}` `{seat}` `{name}` `{floor}` `{from}` `{opens}` `{closes}` `{code}` `{rows}` `{cols}` `{angle}` `{id}`** 는 글자 하나 바꾸지 말고 그대로 둔다(어순에 맞게 위치만 옮겨도 된다).
2. 열쇠에 HTML 태그(`<b>`, `<small>`, `<strong>`)가 있으면 번역에도 **같은 태그를 같은 개수로** 둔다.
3. `[연결]` `[저장]` `[공개]` `[연결 끊기]` 처럼 대괄호 안의 이름은 **찜콩 화면의 단추 이름**이다. 그 단추 문구를 번역한 말과 똑같이 맞춘다(예: 영어에서 '연결' 단추를 Connect 로 했다면 `[Connect]`).
4. **`찜콩` 은 서비스 이름**이라 번역하지 않고 그대로 둔다. 단, `{seat} 찜콩! 자리를 잡았어요.` 의 `찜콩!` 은 "됐다! 맡았다!" 같은 기쁜 외침이므로 뜻으로 옮긴다.
5. 좌석 이름표(A1, B2 …), 확인 번호, URL, `demo`, `https://script.google.com/…/exec` 같은 코드는 그대로.
6. 구글 시트 안의 메뉴 이름은 시트가 한국어로 되어 있어 **화면에 한국어로 보인다**. 사용법에서 `[좌석 예약]`, `[1. 처음 설정 시작]`, `[2. 연결 QR 보기]`, `[웹 앱 주소 다시 넣기]`, `[관리자 키 새로 만들기]` 같은 시트 메뉴 이름은 **한국어 원문을 그대로 두고 괄호로 뜻을 붙인다**. 예: `[2. 연결 QR 보기] (Show connection QR)`. 시트 탭 이름(설정 · 좌석 · 예약 · 지난 예약 · 기록)도 같은 방식.
7. 구글 자체 화면(확장 프로그램, Apps Script, 배포, 새 배포, 웹 앱, 실행 계정, 액세스 권한, 모든 사용자, 배포 관리, 새 버전, 사본 만들기, 고급, 허용 …)은 사용자의 구글이 그 언어로 보여 주므로 **그 언어의 구글 공식 메뉴 이름**으로 옮긴다(모르면 가장 흔한 뜻으로).
8. 카톡 · 카카오톡은 `KakaoTalk` 으로. "나와의 채팅"은 KakaoTalk 의 '나와의 채팅(Chat with myself)' 기능이다.

## 용어
| 한국어 | 뜻 · 쓰임 |
|---|---|
| 찜, 찜하다 | 자리를 미리 맡다(reserve / save a seat). 가볍고 친근한 말 |
| 찜콩 | 서비스 이름(번역 안 함) |
| 빈자리 | 아직 아무도 맡지 않은 자리 |
| 내 자리 | 내가 맡은 자리 |
| 예약됨 · 찜함 | 다른 사람이 맡은 자리 |
| 앉을 수 없음 | 관리자가 막아 둔 자리 |
| 관리자 | 교회 담당자(administrator / organizer) |
| 성도 | 교인(church members). 손님도 포함되는 맥락이면 "참석자"로 풀어도 됨 |
| 배치도 | 좌석 배치도(seating chart / floor plan) |
| 강단 · 앞 (강단) | 예배실 맨 앞 단상(stage / platform at the front) |
| 강대상 | 설교자가 서는 받침대(pulpit / lectern) |
| 무대 | 둥근 무대(stage) |
| 외벽 | 강의실 바깥 벽(outer wall) |
| 1인 의자 · 책상 의자 · 장의자 · 보조 의자 | single chair · desk chair · pew(긴 의자) · extra(folding) chair |
| 통로 (지우기) | 의자를 지워 통로로 만드는 도구(aisle / erase) |
| 판 | 배치도를 그리는 바둑판 격자(grid) |
| 줄 · 칸 | row · column |
| 층 | floor (`{n}층` → "Floor {n}" 등) |
| 회차 | 행사 회차(session / round) |
| 연결 코드 | 좌석 예약에 연결하는 링크/주소(connection code) |
| 확인 번호 | 가짜 링크를 가려내는 8글자 번호(verification code) |
| 초대 링크 · 초대 QR | invitation link · invitation QR |
| 내 자리 링크 | 내 자리로 바로 들어오는 개인 링크(my seat link) — 남에게 주면 안 됨 |
| 내 자리 지키기 · 되찾기 | protect · recover my seat |
| 시트 · 좌석 예약 시트 | 구글 스프레드시트(Google Sheet) |
| 웹 앱 · 배포 | Apps Script 웹 앱 · deploy |
| 공개 | 예약을 성도에게 여는 것(publish / open) |
| 체험해 보기 · 체험 모드 | 데모(try the demo · demo mode) |
