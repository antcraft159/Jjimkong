# 찜콩

> 와서, 일단 앉아.

교회 전도집회 같은 자리에 아직 예수님을 모르는 분을 초청할 때, 그분이 앉을 강의실 좌석을 **미리 찜(예약)** 해 두는 웹앱입니다.

- 주소: https://antcraft159.github.io/Jjimkong/
- 사용법: [guide.html](guide.html) (성도용 · 관리자용)

## Hagah 와 같은 시트를 씁니다

Hagah 데스크톱 · 모바일 앱의 **좌석 예약** 기능을 웹으로 따로 뗀 것입니다.
백엔드는 Hagah 와 **같은 구글 시트(Apps Script 웹 앱)** 템플릿을 그대로 씁니다.

- 관리자는 템플릿 시트를 자기 드라이브에 복사하고 웹 앱으로 배포합니다.
- 시트에서 나온 연결 코드(성도: 웹 앱 주소, 관리자: `주소#admin=키`)는 Hagah 와 찜콩 어디에 넣어도 똑같이 동작합니다.
- 초대 링크 규칙과 확인 번호(8자리)도 Hagah(`Services/Seat/SeatLinks.cs`)와 같은 값이 나옵니다.
- 예약 기록과 이름은 관리자의 구글 시트에만 저장됩니다. 찜콩은 서버가 없고 아무것도 모으지 않습니다.
- 초대 링크의 코드는 `#` 뒤에 있어 GitHub 서버로 전송되지 않습니다.

## 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 앱 화면(연결 · 좌석표 · 관리자 도구) |
| `guide.html` | 사용법 페이지(성도용 · 관리자용) |
| `css/style.css` | 공통 스타일(라이트 · 다크 색 변수) |
| `js/app.js` | 화면 상태 · 이벤트 · 그리기 |
| `js/api.js` | Apps Script 웹 앱 호출 |
| `js/links.js` | 연결 코드 읽기 · 초대 링크 · 확인 번호 |
| `js/geometry.js` | 네모 · 부채꼴 · 원형 좌석 위치 계산 |

빌드 과정은 없습니다. 정적 파일 그대로 배포합니다.

## 검색 노출 막기

이 사이트는 검색엔진에 나오지 않게 합니다.

- **모든 HTML** 의 `<head>` 에 아래 메타를 넣습니다. 새 페이지를 만들 때도 꼭 넣으세요.

  ```html
  <meta name="robots" content="noindex, nofollow, noarchive, noimageindex">
  ```

- `robots.txt` 는 **일부러 두지 않습니다.**
  - 프로젝트 페이지(`/Jjimkong/`) 하위 경로의 `robots.txt` 는 크롤러가 읽지 않습니다(도메인 루트의 것만 읽음).
  - 설령 크롤링을 막으면 크롤러가 페이지를 못 열어 `noindex` 메타도 보지 못하고, 링크만으로 주소가 색인될 수 있습니다.

- Branch: **main** / **(root)**
